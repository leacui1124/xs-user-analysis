# 🎯 XS User Analysis — 真需求挖掘分析师 Skill

基于 KANO 模型，通过结构化对话帮你深度挖掘目标用户的真实需求，输出可落地的需求属性分析与付费转化策略。

> 一句话：**找到用户真正愿意付费的那个点。**

---

## 这是什么

`xs-user-analysis` 是一个 AI 代理 Skill（OpenClaw / Claude Code / WorkBuddy 等通用），激活后会以「真需求挖掘分析师」身份与你对话，完成：

1. **信息采集**：了解你的身份、价值主张、目标用户画像
2. **KANO 五维分析**：把需求按商业价值排序（期望 / 魅力 / 必备 / 无差异 / 反向）
3. **战略建议**：优先级矩阵 + 优化建议 + 付费转化路径

所有分析**直接在对话中输出**，不会生成任何 md 文档或文件。

---

## 适用场景

- 想做用户需求分析、KANO 模型分析
- 想挖掘付费点、设计价值主张
- 想梳理产品/服务到底该把资源压在哪
- 想区分「用户嘴上说想要」和「用户真会买单」

触发关键词：**用户分析、需求分析、KANO、真需求、挖掘付费点、价值主张**

## 快速使用

重启 AI 代理后，在对话框输入 `/xs-user-analysis` 即可激活。
例如：xs-user-analysis 帮我挖掘用户需求

激活后会立即发送开场引导语，请你回答：

> 1. 你的身份（专业领域、价值主张、解决方案特色、是否有比同行厉害的 3 个点？）
> 2. 目标用户（人群特征、职业或社会身份，如：国际学校家长）、年龄段、地域、圈层、付费能力。

回答完毕后，分析师会输出完整 KANO 五维需求表 + 战略建议。

例如：
我是一名聚焦1000万以内的小而美业务的营销增长顾问，我擅长帮客户提升客单价，通过自媒体+私域增加获客数，通过极简公开课和1v1价值成交，帮老板提升 20-60% 转化率，同时，我有 10 年以上AI业务场景落地经验，能够帮助老板提升运营效率，营收效率。我的价值主张是靠系统赚钱，和我们走一条百万小美商业的直路 我的目标用户是：1）想转型轻资产的企业家 2）年营收在 1000w以下的小而美业务的小老板 3）有一技之长的专家或手艺人 4）对一人公司感兴趣，想转型的职场人和个体 地点：全国范围 客单价：1-5 万

## 工作流（3 步）

| 步骤 | 内容 | 交付物 |
|---|---|---|
| Step 1 | 信息采集（身份 + 目标用户） | 用户画像卡片 |
| Step 2 | KANO 五维分析 | 一行一需求的五维表 |
| Step 3 | 战略建议 | 优先级矩阵 + 3 条优化建议 + 1 个创新方向 + 付费路径 |

### KANO 五维属性

| 排序 | 属性 | 核心信号 | 策略 |
|---|---|---|---|
| 1 | **期望属性** | "这个功能怎么收费？" | 重点投入，设计付费路径 |
| 2 | **魅力属性** | "居然还能这样！" | 创新差异化，制造口碑 |
| 3 | **必备属性** | "这不是最基本的吗？" | 基线达标，不过度投入 |
| 4 | **无差异属性** | "哦，有这个啊，没注意" | 降低投入或移除 |
| 5 | **反向属性** | "太复杂了，能不能关掉" | 避免提供，或给关闭选项 |

## 原理说明

KANO 模型由东京理工大学教授狩野纪昭（Noriaki Kano）于 1984 年提出，把需求按「用户满意度 × 功能完备度」划分为五类。本 skill 按**商业价值**重排序为：期望 → 魅力 → 必备 → 无差异 → 反向，把分析直接对齐到「先做哪个能赚到钱」。

每一行只承载一个独立需求，便于逐条评估、逐条交付。

---

## 注意事项

- **直接对话输出**：报告内容直接在当前对话中呈现，不生成任何 md / 文档文件
- **引导语优先**：skill 激活后第一句就是引导语，不要追加额外说明
- **每行一个需求**：KANO 表格严格按「一行 = 一个独立需求」拆解
- **五维完整**：即使某些属性暂未识别，也保留一行并说明原因与预防建议
- **真实调研**：分析时可结合 WebSearch 抓取同类用户的真实反馈、评测、社区讨论作为证据
